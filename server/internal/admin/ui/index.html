How much CPU bots may use, and which bot plays the AI seats

Governor

The governor keeps bots from taking more CPU than this server can spare. Enforce: a bot seat it cannot afford plays a cheaper version (the hand-written bot instead of the model, Medium instead of Hard) from its next turn, and goes back up at the next round when there is room. Observe: decides and counts, changes no move. Off: does nothing. Takes effect at once; survives restarts.

Trained models

Turning a game's model on puts the trained model this build ships in every AI bot seat, at every table, from its next turn. Easy, Medium and Hard seats and player hints keep the hand-written bot. Off by default; the setting survives restarts.
